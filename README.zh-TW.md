## Megingiard-ZH 繁體中文增強版特色

本分支（`megingiard-zh`）專為台灣及繁體中文使用者提供深度的在地化精修與掌機操作最佳化：

- **獨立 Package ID**：採用 `com.stormpanda.megingiard.zh` 套件識別碼，可與官方原版並存安裝於同一台裝置，設定檔與資料互不干擾衝突。
- **巨集板表格模式（Table Mode）**：自訂網格行列配置（支援 1×1 至 8×6）、支援儲存格拖曳交換與移動、跨格合併按鈕，並具備頂層細白格線全繪製，排版更整齊俐落。
- **自訂按鈕圖片與雙螢幕裁切**：支援從本機儲存空間或 SteamGridDB 挑選按鈕自訂圖示，提供獨立副螢幕放大裁切頁面與全滿版縮放（full-bleed）效果。
- **100% 繁體中文在地化**：完整翻譯所有介面文字、全域設定及功能說明教學彈窗（HelpModal），字詞徹底遵循台灣常見科技標準用語。

## 裝置相容性

- **目標硬體：** AYN Thor（配備上下雙螢幕的 Android 掌上遊戲機）。
- **最低 Android 版本：** Android 13 / API 33（AYN Thor 出廠內建之系統版本）。
- **單螢幕裝置：** **永久不支援。** Megingiard 的架構嚴格建立在主螢幕（上方螢幕）與副螢幕（下方螢幕）同時協同運作的伴侶機制上。單螢幕手機、平板電腦與一般 Android 模擬器皆無法使用。
- **其他裝置：** 不支援。Megingiard 極度依賴硬體特定路徑（如 `/dev/input/event*` 節點、副螢幕硬體通道、AYN Thor 實體按鍵配置），這些在其他手機或掌機上可能不存在。此外，原作者手邊也沒有其他雙螢幕掌機 😅。

## 核心功能

### 1. 零延遲多區域畫面鏡像 (Screen Mirroring)

- **直接硬體管道：** 結合 Android 的 `MediaProjection` 與原生 `VirtualDisplay`，直接輸出至 `SurfaceView`，徹底繞過所有軟體合成與像素複製步驟。
- **多區域裁切配置編輯器：** 最多可設定 10 個主螢幕裁切區域（Cutouts），並在副螢幕上自由拖曳縮放與排版；採用單一 Surface 多重複製架構，杜絕 Token 衝突與畫面卡死。
- **寬高比鎖定模式：** 支援多種長寬比鎖定方式 —— _自由調整 (Free)_ 獨立調整尺寸、_鎖定來源比例 (Top)_ 等比例縮放，以及 _鎖定目標視窗比例 (Bottom)_ 自動適配來源。
- **邊緣漸變與圓形遮罩：** 支援最高 100 dp 的邊緣疊加漸變，消除不同視窗拼接處的黑邊與硬邊；亦可一鍵切換為正圓形鏡像視窗。
- **時間動態平滑化 (Temporal Motion Smoothing)：** 提供關閉、輕微、中度、強力四段 EMA 移動平均濾波，有效穩定個別裁切視窗中的遊戲 UI 震顫。
- **跟隨觸控模式 (Follow Touch Mode)：** 即時追蹤主螢幕觸控點，副螢幕鏡像視窗會自動以當前縮放倍率平滑跟隨最後觸控的位置。可設定在執行巨集期間暫時停用，避免鏡像畫面與巨集觸控發生移動衝突。
- **高度自訂控制項：** 可將鏡像控制鍵（啟動 / 停止 / 畫面凍結 / 視角重設）直接以按鈕形式擺放在自訂巨集板上，或透過常駐的邊緣快捷選單進行操作。
- **實際操作展示：** 觀看 YouTube Shorts 上的 [dylosama 畫面鏡像展示短片](https://www.youtube.com/shorts/v_UhWzfCbRQ)。

### 2. 巨集板控制中心 (MacroPad Central Mode)

- **高度自訂按鈕面板：** 建立多個具名設定檔與版面配置，自由擺放不同大小、形狀與動作的按鈕。
- **多元動作綁定：** 按鈕可對應標準鍵盤按鍵、控制器按鈕、滑鼠按鈕、滾輪，或虛擬小紅點搖桿（相對滑鼠移動/虛擬觸控）。
- **強大版面編輯器：** 支援拖曳擺放按鈕、矩形或放射狀磁吸格線，內建收錄超過 4,000 個圖示的 Material Symbols 向量圖示庫。
- **應用程式自動感知切換：** 將特定設定檔與 Android 應用程式綁定。當主螢幕啟動該遊戲或應用時，副螢幕會透過高效率的專屬**無障礙服務 (Accessibility Service)**（具備系統 UI 排除機制以防焦點迴圈）立即無縫切換至對應的巨集板，並在設定中提供即時連線狀態燈。
- **視覺化巨集錄製與編輯：** 直覺編排或即時錄製鍵盤、滑鼠、手把按鍵的時間序列事件。可直接錄製螢幕觸控，或在特權模式下直接記錄實體手把按鍵。內建**隨機延遲模擬器**（每一步驟動態增加 10ms 至 100ms 隨機位移），模擬人類真實按鍵行為。

### 3. 虛擬鍵盤 (Virtual Keyboard)

- **多種螢幕鍵盤配置：** 提供 **QWERTZ / QWERTY / AZERTY** 完整螢幕鍵盤配置、數字鍵列、F1–F12 功能鍵、方向鍵及標準修飾鍵。
- **智慧修飾鍵：** 輕觸修飾鍵（Shift、Ctrl、Alt、Meta）即可啟用單次黏滯功能，長按則可鎖定按住。
- **整合式虛擬小紅點 (Trackpoint)：** 直接透過鍵盤中央的虛擬搖桿操控主螢幕上的滑鼠游標。
- **核心層級連打控制：** 可自訂按鍵連打頻率；停用連打時，放開按鍵會立即傳送 key-up 訊號以壓制系統核心自動連打。

### 4. 虛擬觸控板 (Virtual Touchpad)

- **核心層級滑鼠模擬：** 將副螢幕轉化為精準的相對座標觸控板，由 Android 系統直接辨識為實體滑鼠裝置。
- **亞毫秒級反應速度：** 觸控事件透過原生二進位程式（`/dev/uinput`）直通 Linux 核心輸入串流，延遲低於 1ms。
- **多指手勢支援：** 簡單可靠的手勢操作：單指輕觸代表滑鼠左鍵、雙指輕觸代表滑鼠右鍵、三指輕觸代表滑鼠中鍵。

### 5. 邊緣快捷選單與沉浸式介面 (Quick Menu & Immersive UI)

- **常駐邊緣快捷選單列：** 副螢幕底部邊緣常駐極簡手勢指示條，向內輕滑即可呼出邊緣快捷選單，無需離開當前畫面即可隨時切換工具（鏡像、巨集板、鍵盤、觸控板）、變更設定檔、控制畫面鏡像或開啟設定。
- **沉浸式深色遊戲美學：** 專為雙螢幕遊戲環境打造的無邊框全螢幕深色主題，避免副螢幕過亮干擾主螢幕遊戲體驗。

## 安裝方式

1. 從 GitHub 儲存庫的 [Releases](../../releases) 頁面下載最新簽名之 `Megingiard-vX.Y.Z.apk`（或繁中分支專用之 `Megingiard-vX.Y.Z-zh.apk`）。
2. 在 AYN Thor 上，允許瀏覽器或檔案管理員安裝未知來源應用程式（Android 設定 → 應用程式 → <您的檔案管理員> → 「安裝未知應用程式」）。
3. 點選 APK 進行安裝。
4. 啟動 Megingiard 開始設定！

本應用程式未上架 Google Play 商店，直接下載 APK 安裝為唯一官方發行管道。

## 初次啟動與快速上手

1. **啟動應用程式：** 請由副螢幕（下方螢幕）啟動 Megingiard，或將桌面啟動器設定為預設在副螢幕開啟本程式。
2. **設定無障礙服務（選用）：** 若需使用**應用程式自動感知切換設定檔**功能：
   - 進入 Android 系統設定 → 無障礙 → 已下載的服務 / 已安裝的應用程式。
   - 找到 **Megingiard Accessibility Service** 並將其啟用。
   - 在 Megingiard 全域設定中開啟「自動切換設定檔」選項。
3. **呼出邊緣快捷選單：** 在副螢幕底部的邊緣指示條向內滑動，即可：
   - 切換使用中的工具（鏡像、巨集板、鍵盤、觸控板）。
   - 切換巨集板設定檔與版面配置。
   - 啟動、凍結或停止畫面鏡像。
   - 開啟全域設定頁面。
4. **結束應用程式：** 透過 Android 系統「最近使用的應用程式（Recents）」列表滑掉關閉即可。應用程式內未設置離開按鈕，以維持副螢幕介面極簡乾淨。

## 特權模式 (Privileged Mode)

特權模式是一項**自由選擇啟用的進階功能**，能突破 Android 標準應用程式沙盒的安全限制。本功能**預設為關閉**，隨時可在全域設定中自由開啟或關閉。

### 原理與技術細節

Megingiard 在 APK 內打包了極為輕量的原生輔助守護行程（`megingiard_privd`）。啟用特權模式時，內建精靈會利用 Android 11+ 原生的**無線除錯 (Wireless Debugging)** 機制，將守護行程部署至 `/data/local/tmp`，並以 **Shell 使用者 (UID 2000)** 身分在背景運行（等同於執行 `adb shell`）。應用程式接著透過安全的行程本機 Unix Socket 與守護行程建立通訊。

**全程無需 Root 權限、無需連接電腦、無需傳輸線、亦無需外部伺服器**，所有引導流程皆在裝置本機全自動完成。

### 特權功能解鎖對比

| 功能特性 | 啟用特權模式後體驗 | 未啟用的沙盒替代方案 |
| :--- | :--- | :--- |
| **手把合併 (Gamepad Merge)** | 遊戲只會識別到**單一**實體控制器，巨集板的虛擬輸入無縫疊加於實體手把訊號之上。 | 系統會出現第二個虛擬手把，部分遊戲可能會忽略第二控制器的訊號。 |
| **手把巨集實體錄製 (Gamepad Recording)** | 遊戲正常操控的同時，直接捕捉並錄製**實體手把按鍵**的真實輸入序列與間隔。 | 需使用副螢幕上的虛擬控制器覆蓋面板進行錄製。 |
| **特權免提示鏡像 (Privileged Mirror)** | 畫面鏡像隨點即開，不再反覆跳出系統錄影授權對話方塊。 | 每次啟動鏡像時皆會跳出 Android 標準螢幕錄製確認視窗。 |

### 為何技術上必須如此設計

Android 標準應用程式沙盒（運行於 `untrusted_app` SELinux 網域，且無 `input` 權限群組成員資格）嚴格禁止直接寫入 `/dev/uinput` 或實體 `/dev/input/event*` 節點，亦無法直接發起系統 `SurfaceControl` 鏡像路徑。Android Shell UID 擁有必要的 `input` 群組權限以及更為寬鬆的 SELinux 規範，因此能實現原生輸入注入與投影控制。

### 便利性效益

- **自動連線：** 一旦設定完成，Megingiard 在冷啟動時會靜默自動重新連線至本機背景守護行程，無需再次手動配對。
- **免重複提示：** 特權鏡像徹底消除每次啟動時作業系統跳出的螢幕錄製安全警告。
- **個別功能開關：** 可自由挑選要透過特權模式運行的特定功能，其他功能則維持標準沙盒模式。
- **⚠️ 背景守護行程生命週期提醒：** 背景守護行程在**掌機重新開機後不會自動保留**，因為 Android 系統每次開機都會清空 `/data/local/tmp`。重新開機後只需再次開啟全域設定中的自動配對精靈（全程只需約 10~30 秒）即可恢復。

### 安全性與信任機制

特權模式功能強大，因此應充分了解其安全範疇：

- **Shell 層級權限範圍 (UID 2000)：** 背景守護行程僅具有與 `adb shell` 相同的權限。它可以讀寫輸入節點以模擬控制器與按鍵，但**無法**提升為 Root 權限、無法修改系統唯讀分割區，亦無法讀取其他應用程式的私有資料。
- **僅自信任來源下載：** 請僅在信任原始碼與簽名發布版的情況下啟用特權模式。**請務必僅從 GitHub 官方 Releases 頁面下載 APK。**
- **完全本機離線運作：** 無線除錯配對僅在裝置本機內部迴路（Loopback）進行交握。背景守護行程僅監聽外部網路完全無法存取的抽象 Unix Socket。Megingiard 不會發起任何對外網路連線。
- **隨時可輕鬆停用：** 您可隨時在設定中關閉特權模式，所有功能將無縫平退回標準沙盒模式。

### 驗證 APK 下載完整性

每個發布版本均附帶 SHA-256 校驗碼檔案（例如 `Megingiard-vX.Y.Z-checksum-sha256.txt`）。安裝前請驗證下載之 APK 雜湊值以確保其完整性。

**macOS**

```sh
shasum -a 256 Megingiard-vX.Y.Z.apk
```

**Linux**

```sh
sha256sum Megingiard-vX.Y.Z.apk
```

**Windows (PowerShell)**

```powershell
Get-FileHash Megingiard-vX.Y.Z.apk -Algorithm SHA256 | Select-Object -ExpandProperty Hash
```

在側載安裝前，請確認指令輸出與 `.txt` 檔案中的校驗碼完全一致。

### 自動配對精靈步驟

1. 進入 Android 設定 → 系統 → 開發人員選項，開啟**無線除錯**。
2. 輕觸**「使用配對碼配對裝置」** —— Android 系統會顯示 IP 位址、通訊埠以及 6 位數配對碼。
3. 將通訊埠與配對碼輸入 Megingiard 的設定精靈中。
4. 精靈會自動與本機 ADB 服務完成配對、部署背景守護行程、啟動行程並執行自我檢測。
5. 隨時可在全域設定中輕觸**「測試連線」**以確認 Socket 連結正常運作。

## 常見問題與疑難排解

**畫面鏡像呈現黑畫面？**

> 請嘗試由邊緣快捷選單停止並重新啟動鏡像。若問題持續，請於 GitHub 提交 Issue 並附上當前應用程式版本與重現步驟。請注意若主螢幕運行保護版權（DRM）內容之應用程式，畫面亦會被保護遮蔽。

**每次啟動鏡像都會詢問螢幕錄製權限？**

> 此為 Android 標準安全行為。啟用「特權模式」並開啟設定中的「特權免提示鏡像」，即可永久略過此提示。

**掌機重新開機後特權模式顯示為「關閉」？**

> 這是 Android 系統預期機制。系統重開機時會清空 `/data/local/tmp`。非 Root 應用程式無法設定開機自動啟動背景守護行程。只需進入設定重新執行配對精靈（約 30 秒）即可。

**使用巨集板時，遊戲同時辨識到兩個控制器？**

> 請開啟「特權模式」並啟用「手把合併 (Gamepad Merge)」，即可將巨集板的虛擬輸入直接與實體手把訊號融為一體，對遊戲隱藏第二個控制器。

**只有巨集板按鈕或只有實體手把輸入有反應，無法同時生效？**

> 部分 Android 遊戲僅接受單一使用中的輸入來源。在特權模式下啟用「手把合併」即可解決此問題。

**無線除錯自動配對失敗？**

> 請確認您輸入的是「使用配對碼配對裝置」彈出對話方塊中的 5 位數**配對通訊埠 (Pairing Port)** 與 6 位數配對碼，而非無線除錯主畫面上的 IP 通訊埠。兩者為不同且動態產生的五位數埠號。

**部署背景守護行程失敗？**

> 有時本機 ADB 內部迴路交握需要額外的初始化時間。請嘗試再次點選測試/部署 1 至 2 次，通常即可解決暫時性的 Socket 連線逾時問題。

**能否在其他雙螢幕裝置或手機上執行？**

> 無法。Megingiard 是專門針對 AYN Thor 的特定螢幕幾何比例、硬體特定對應路徑與實體事件碼進行設計，無法在不同的硬體配置上運作。

**為什麼應用程式自動感知切換沒有生效？**

> 1. 請確認已啟用 Megingiard 的**無障礙服務**（Android 設定 → 無障礙 → Megingiard Accessibility Service）。
> 2. 請確認全域設定中的「自動切換設定檔」開關已開啟。
> 3. 請確認設定檔編輯器中已正確對應應用程式（如有需要可輕觸「清除應用程式對應」並重新選取）。
> 4. 請注意：當 Megingiard 本身、核心系統介面（`com.android.systemui`）或系統對話方塊（`android`）處於前景時，會主動忽略切換以避免發生焦點迴圈。
